## 2. 게임 사양

### 2.1 핵심 루프

```
미술관(아지트)
  → 스테이지 선택·입장 (체력 최대로 시작)
  → 한 발 사격 · 회수 · 적 처치 → 재료는 '전투 가방'에 임시 보관
  → 모든 적 처치(클리어) → 재료를 창고로 정산   /   사망 → 전투 가방 전부 삭제
  → 종이 합성 → 그림 제작 → 액자 전시
  → 서로 다른 그림 9장이 액자에 걸리면 엔딩
```

### 2.2 조작

| 입력 | 기능 |
|---|---|
| WASD | 이동 |
| 마우스 | 3인칭 카메라 회전, 조준 |
| 좌클릭 | 사격 |
| Space | 점프 |
| Shift | 달리기 |
| Q | 회피 |
| E | 상호작용, 탄환 회수 |
| ESC | 일시정지, 설정 |

- 카메라는 캐릭터 뒤를 따라가는 3인칭이다. 화면 중앙에 크로스헤어가 있다.
- 그림판이 열려 있는 동안 이동·카메라·사격을 막고 마우스 커서를 표시한다.

### 2.3 플레이어

| 항목 | 값 |
|---|---|
| 체력 | 100. 스테이지 입장 시 최대로 회복, 전투 중 회복 수단 없음 |
| 걷기 / 달리기 | 4.5m/s / 7m/s (기본값) |
| 점프 높이 | 1.5m (기본값) |
| 회피 | 거리 3m, 쿨타임 1.2초, 무적 0.3초 (기본값) |
| 상태 | `Idle`, `Move`, `Jump`, `Dodge`, `Attack`, `Interact`, `Dead`, `Drawing` |

### 2.4 한 발 탄환 전투

1. 플레이어는 탄환을 한 발만 가진다.
2. 장전 상태에서 좌클릭하면 발사한다. 판정은 Raycast로 한다.
3. **머리에 명중하면** 즉사하고 탄환을 즉시 다시 쓸 수 있다 (헤드샷 원탭).
4. **몸에 명중하면 피해가 없다.** 적은 빨갛게 깜빡이며 잠깐 멈칫하고, 탄환은 빗나간 것과 같이 떨어진다. (2026-10-30 변경: 원래 몸 피해 15, 명중 시 즉시 재사용)
5. **빗나가거나 몸에 맞으면** 탄환이 맞은 지점에 떨어지고, 그동안 사격할 수 없다. 아무것도 맞지 않았다면 최대 사거리 지점 아래 바닥에 떨어진다.
6. 떨어진 탄환 근처에서 E키를 누르면 회수한다.
7. 떨어진 탄환은 위치와 관계없이 **7초 후 자동으로 돌아온다.** (2026-10-30 15초에서 변경)
8. 탄환이 없는 동안에는 회피·도주만 할 수 있다.
9. 적 처치(헤드샷)는 보상을 1회만 지급한다.

**구현 기준**
- 탄환 상태: `Loaded`, `Fired`(중복 발사 방지), `Dropped`. 구현은 `Loaded`/`Dropped` 위주로 한다.
- 조준: 카메라 중심 Raycast로 목표점을 구한 뒤 총구에서 그 점으로 다시 판정한다.
- 헤드샷: 적 프리팹에 머리용 Sphere Collider를 자식으로 두고 `Hitbox` 컴포넌트로 머리/몸을 구분한다.
- 탄환 위치 안내: 탄환이 화면 밖에 있으면 화면 가장자리에 방향 화살표, 탄환 위에는 빛 기둥 이펙트를 표시한다. 자동 복귀까지 남은 시간은 원형 게이지로 보여 준다.
- 헤드샷에는 전용 효과음과 이펙트를 넣는다.

### 2.5 적

| 적 | 행동 | 공격 | 이동 (기본값) | 처치 |
|---|---|---:|---|---|
| 돌진형 | 발견 후 추적, 근거리 돌진 | 15 | 추적 4m/s, 돌진 9m/s | 헤드샷만 |
| 원거리형 | 거리 유지, 투사체 공격 | 12 | 3m/s, 투사체 12m/s, 2.5초 간격 | 헤드샷만 |
| 방어형 | 정면 방패, 측면·후방 공략 | 20 | 3m/s, 회전 느림 | 측면·후방 헤드샷만 |

(2026-10-30 변경: 헤드샷 원탭 전용 게임. 적 HP와 몸샷 처치 횟수를 없앴다.)

- 난이도는 **보통과 어려움 사이**다. 플레이어는 적 공격 5~8대에 사망한다.
- AI 상태: `Idle` → `Chase` → `Attack`, 피격 `Hit`, 사망 `Dead`. 원거리형은 `KeepDistance` 상태를 추가로 가진다.
- 모든 적은 공격 0.5초 전에 예고 동작을 한다.
- 방어형의 방패(정면 ±60°, 기본값)에 맞은 탄환은 **명중으로 처리**한다. 피해는 0이고 탄환은 즉시 다시 쓸 수 있다. 정면 헤드샷도 방패가 막는다.
- 드롭은 적 종류와 관계없이 같다: **종이조각 1개 + 9색 중 랜덤 1색 물감 50.**
- 사망 처리는 한 번만 실행해 드롭이 중복 지급되지 않게 한다.

### 2.6 스테이지

| 스테이지 | 역할 | 적 구성 (기본값) |
|---|---|---|
| 훈련장 | 이동·사격·헤드샷·회수 학습 | 돌진형 3 |
| 숲 | 본 전투, 재료 파밍 | 돌진형 3 + 원거리형 2 + 방어형 2 |

- 1판 목표 시간은 **약 4분**이다.
- 해금: 처음에는 훈련장만 열려 있고, 훈련장을 클리어하면 숲이 열린다.
- 클리어 조건은 스테이지의 모든 적 처치다. 클리어한 스테이지는 몇 번이든 다시 할 수 있고, 다시 들어가면 적이 새로 배치된다.
- 스테이지 도중에는 나갈 수 없다. ESC 메뉴의 '포기'는 사망과 같이 처리한다.
- **사망하면 그 판에서 얻은 재료를 모두 잃는다.** 창고 재료, 그림, 전시 상태는 영향받지 않는다. 사망 후에는 미술관으로 돌아간다.
- 전투 중 화면에 전투 가방 내용(이번 판 획득량)을 작게 표시한다.

### 2.7 재료와 물감

| 아이템 | 획득 | 사용 |
|---|---|---|
| 종이조각 | 적 처치 시 1개 | 5개로 그림용 종이 1장 합성 |
| 그림용 종이 | 미술관 합성대에서 합성 | 그림 완성 버튼을 누를 때 1장 소비 |
| 물감 9색 | 적 처치 시 랜덤 1색 50 | 그리는 동안 실시간 소비 |
| 펜 | 처음부터 1개 보유 | 영구 도구, 굵기 4단계 |

**물감 9색** (UI 색상 코드는 기본값)

| 빨강 | 주황 | 노랑 | 초록 | 파랑 | 남색 | 보라 | 하양 | 검정 |
|---|---|---|---|---|---|---|---|---|
| `#EF4444` | `#F97316` | `#FACC15` | `#22C55E` | `#3B82F6` | `#3730A3` | `#A855F7` | `#FFFFFF` | `#171717` |

- 색상별 최대 보유량은 500이다. 500을 넘는 획득분은 버리고 "가득 참" 알림을 표시한다.
- 색은 9색 중 균등한 확률로 랜덤하게 정해진다. 원하는 색만 골라 얻는 수단은 없다.
- 잔량이 0인 색으로는 그릴 수 없다.
- 지우개는 물감을 쓰지 않는다. 지워도 이미 쓴 물감은 돌려주지 않는다.
- 그림을 취소하거나 중단해도 쓴 물감은 돌려주지 않는다.
- **소비 공식:** `소비량 = 선 길이(px) × 펜 굵기(px) × 0.01`
  - 선 길이는 마우스 이벤트 횟수가 아니라 이전 점과 현재 점 사이 거리로 계산한다.
  - 소수 누적값은 내부에 보관하고, 인벤토리는 정수 단위로 차감한다.
  - 그림 1장 분량(약 250)으로 256×256 캔버스의 약 40%를 칠할 수 있다.

**엔딩까지 필요한 양 (참고)**
- 종이 9장 = 종이조각 45개 = 적 약 45마리 = 숲 약 6~7판
- 예상 총 플레이 시간: 약 1.5~2시간

### 2.8 그림판

- 미술관의 **그림 작업대**에서 E키를 누르면 같은 `Hideout` 씬 위에 2D UI로 열린다. 별도 씬으로 이동하지 않는다.
- 구성: 펜(굵기 2 / 5 / 10 / 20px), 색상 9종, 지우개, 물감 잔량 표시, 완성 버튼, 취소 버튼.
- 캔버스는 256×256px (기본값)이다.
- 그림판을 열거나 그리기 시작할 때는 종이를 쓰지 않는다.
- **완성 버튼을 누르면 종이 1장을 소비하고** PNG로 저장한 뒤, 고유 ID로 작품 목록에 등록한다. 종이가 없으면 완성할 수 없다.
- 내용과 관계없이 완성할 수 있다. 빈 캔버스도 된다.
- PNG 저장에 성공한 뒤에만 종이를 차감한다.
- 취소하면 미완성 그림을 삭제한다. 쓴 물감은 돌려주지 않고 종이는 쓰지 않는다. 취소 전에 확인창을 띄운다.
- 강제 종료나 크래시는 취소와 같이 처리한다. 대비를 위해 그리는 동안 물감 잔량을 5초마다 자동 저장한다.
- 작품 저장 개수에는 제한이 없고, 목록은 스크롤로 보여 준다. 작품 삭제 기능은 넣지 않는다.

### 2.9 미술관과 전시

- 미술관 구성: 그림 작업대, 종이 합성대, 액자 9개, 스테이지 선택 장치(문 또는 지도), 인벤토리 UI.
- 액자 9개는 처음부터 모두 있다.
- 액자 앞에서 E키 → 작품 목록 → 그림 선택 → 액자 머티리얼의 텍스처를 교체하고, 전시 정보를 저장한다.
- 같은 그림을 여러 액자에 걸 수 있다. 전시해도 그림은 없어지지 않고 언제든 교체할 수 있다.
- 액자 UI에 "서로 다른 작품 N / 9" 진행도를 표시한다.

### 2.10 엔딩

- **조건:** 9개 액자에 **서로 다른 그림 ID 9개**가 걸린 순간. 판정은 그림 ID로 한다. 내용이 같아도 따로 완성한 그림은 서로 다른 작품이다.
- 조건을 충족하면 "이 9점으로 재개관할까요? 이후에는 그림을 바꿀 수 없습니다" 확인창을 띄운다.
- **연출:** 카메라가 액자를 따라 이동하며 걸린 9장을 먼저 보여 주고, 이어서 전시되지 않은 나머지 완성작을 만든 순서대로 각 2초씩 보여 준다. 엔딩 독백 후 "재개관" 문구로 끝난다.
- 엔딩이 끝나면 타이틀로 돌아간다. **엔딩을 본 세이브는 더 이상 플레이할 수 없다.**
- 엔딩 후 타이틀에 **'갤러리 보기'**가 생긴다. 완성된 미술관을 걸어 다니며 감상만 할 수 있고, 전투·그림판·액자 교체는 할 수 없다.
- '새 게임'을 시작할 때 기존 세이브를 덮어쓸지 확인창을 띄운다. PNG 파일은 지우지 않는다.

### 2.11 세계관과 스토리

- **배경:** 폐관한 작은 미술관
- **주인공:** 미술관을 물려받은 젊은 견습 관장. 앞치마와 베레모 차림이고, 밝지만 어설프다.
- **적:** 미술관의 색을 빨아들여 회색이 된 조각상들. 처치하면 가둬 둔 색이 물감으로 터져 나오고, 훔친 작품의 조각이 종이조각으로 떨어진다.
  - 돌진형은 흉상, 원거리형은 돌을 던지는 소형 조각, 방어형은 방패를 든 기사 조각이다 (기본값).
  - 머리를 몸보다 약간 크게 만든다. 헤드샷을 맞으면 머리에 금이 가며 색이 새어 나온다.
- **총:** 창고에 남아 있던 낡은 신호총과 탄환 한 발.
- **전달 방식:** 시작 독백과 엔딩 독백만 넣는다. 각 3~5줄 자막이다.

시작 독백 (초안)
> 할아버지가 남긴 미술관. 열쇠를 받았을 땐 이미 아무것도 없었다.
> 그림도, 색도. 남은 건 빈 액자 아홉 개와… 창고 구석의 낡은 총 한 자루, 탄환 한 발.
> 색을 가져간 건 저 회색 조각상들이다. 되찾아야 한다.
> 내 손으로 다시 채워 보자. 이 미술관을.

엔딩 독백 (초안)
> 아홉 개의 액자가 모두 채워졌다.
> 대단한 그림은 아니다. 그래도 전부 내가 되찾은 색으로 그렸다.
> 오늘, 미술관이 다시 문을 연다.

### 2.12 아트와 에셋

- **로우폴리**, 밝고 캐주얼한 분위기다. 회색 조각상과 원색 물감의 대비가 아트 방향의 중심이다.
- 공포, 바다, 우주, 뜨개질·실 콘셉트는 사용하지 않는다.
- **기성 에셋과 직접 만든 모델을 섞어 쓴다.**
  - 직접 제작 우선순위 (기본값): ① 주인공 ② 조각상 3종 ③ 총·탄환 ④ 액자·작업대
  - 에셋 사용 (기본값): 숲 지형, 나무, 바위, 미술관 기본 건물
  - 스타일 통일 규칙: 단색 머티리얼 또는 팔레트 텍스처 하나, 비슷한 폴리곤 밀도, 같은 조명과 후처리
  - 에셋 출처와 라이선스는 `Assets/Credits.txt`에 기록한다.
- 기능을 구현하는 동안에는 Capsule, Cube 같은 임시 도형을 쓰고, M3에서 모델로 교체한다.

## 3. 기술 설계

### 3.1 스택

| 분야 | 사용 |
|---|---|
| 렌더링 | Unity 6 URP |
| 입력 | New Input System |
| 이동 | CharacterController |
| 카메라 | Cinemachine 3인칭 |
| UI | uGUI + TextMeshPro |
| 사격 | Raycast + `Hitbox` |
| 적 AI | 상태 기반 + NavMesh |
| 그림판 | Texture2D + RawImage, `EncodeToPNG()` |
| 데이터 | JSON (JsonUtility), `Application.persistentDataPath` |
| 씬 간 유지 | `DontDestroyOnLoad` 관리자 |

### 3.2 씬

| 씬 | 역할 |
|---|---|
| `MainMenu` | 새 게임, 이어하기(엔딩 전), 갤러리 보기(엔딩 후), 옵션, 나가기 |
| `Hideout` | 미술관: 작업대, 합성대, 액자 9개, 스테이지 선택. 갤러리 보기 모드 겸용 |
| `Stage_Training` | 훈련장 |
| `Stage_Forest` | 숲 |
| `Ending` | 회고 연출 (`Hideout` 안의 연출로 대체해도 된다) |

흐름: `MainMenu → Hideout ↔ Stage_*` → `Ending` → `MainMenu` → (갤러리 보기) `Hideout`

### 3.3 폴더 구조

```text
Assets/
├── Scenes/            MainMenu, Hideout, Stage_Training, Stage_Forest
├── Scripts/
│   ├── Core/          GameManager, SceneLoader, SaveManager
│   ├── Player/        PlayerMovement, ThirdPersonCamera, PlayerHealth, PlayerInteraction
│   ├── Combat/        OneBulletGun, Hitbox, BulletPickup, BulletAutoReturn, BulletIndicatorUI
│   ├── Enemy/         EnemyAI, EnemyHealth, EnemyDrop
│   ├── Stage/         StageManager, RunBag
│   ├── Inventory/     InventoryManager, PaperCrafting
│   ├── Drawing/       DrawingDeskInteraction, DrawingCanvas, PaintManager, DrawingSaveManager
│   ├── Gallery/       PictureFrame, GalleryManager, EndingSequence
│   └── UI/            BattleUI, InventoryUI, DrawingUI
├── Prefabs/  Materials/  Models/  Textures/  UI/  Audio/  Animations/
└── Credits.txt
```

### 3.4 시스템 연결

- `OneBulletGun` → Raycast → `Hitbox`(머리/몸) → `EnemyHealth`
- `EnemyHealth` 사망 → `EnemyDrop` → `RunBag`(전투 가방)
- `StageManager` 클리어 → `RunBag.Settle()` → `InventoryManager` (상한 500 적용)
- `PlayerHealth` 사망 → `RunBag.Clear()` → `Hideout` 복귀
- `OneBulletGun` 빗나감 → `BulletPickup` 생성 → `BulletAutoReturn` 7초 타이머 → `BulletIndicatorUI`
- `DrawingCanvas` → `PaintManager` → `InventoryManager` 물감 차감
- 완성 → `DrawingSaveManager` PNG 저장 → 성공 시 종이 차감 → 작품 목록 등록
- `PictureFrame` → `GalleryManager` (서로 다른 ID 9개 감지) → 확인창 → `EndingSequence`

### 3.5 저장 데이터

```text
persistentDataPath/SavedData/
├── save.json        # 인벤토리, 물감, 해금 스테이지, 엔딩 여부
├── paintings.json   # 작품 ID, 파일명, 생성일
├── gallery.json     # 액자 9칸의 그림 ID
└── Paintings/       # painting_<ID>.png
```

```json
{
  "paperScraps": 12,
  "drawingPaper": 2,
  "paints": {
    "red": 350, "orange": 210, "yellow": 500, "green": 120, "blue": 430,
    "indigo": 75, "purple": 260, "white": 190, "black": 150
  },
  "unlockedStages": ["Training", "Forest"],
  "endingSeen": false
}
```

- 물감은 메모리에서 바로 차감한다. 디스크에는 주요 상태가 바뀔 때와 그림판을 쓰는 동안 5초마다 저장한다. 마우스 이벤트마다 저장하지 않는다.

## 4. 구현 Phase

각 Phase는 **완료 기준을 모두 통과한 뒤** 다음으로 넘어간다.

### Phase 1 — 프로젝트 설정
- [ ] Unity 6 URP 프로젝트 생성, New Input System 활성화
- [ ] 3.3 폴더 구조 생성, `Hideout` 씬 생성
- [ ] Cinemachine, TextMeshPro 설치

**완료 기준:** 빈 `Hideout` 씬이 오류 없이 재생된다.

### Phase 2 — 플레이어
- [ ] 바닥, 임시 Capsule 플레이어, CharacterController
- [ ] 3인칭 카메라, 크로스헤어 UI
- [ ] 이동, 달리기, 점프, 회피(무적 시간 포함)

**완료 기준:** WASD, Shift, Space, Q가 2.3 수치대로 동작하고 카메라가 자연스럽게 따라온다.

### Phase 3 — 한 발 탄환
- [ ] 발사, 명중 판정(카메라 목표점 → 총구 재판정)
- [ ] 명중 시 즉시 재사용, 빗나가면 탄환 오브젝트 생성
- [ ] E키 회수, 7초 자동 복귀와 원형 게이지
- [ ] 방향 화살표 UI, 빛 기둥 이펙트

**완료 기준:** 탄환이 동시에 2개 생기지 않는다. 벽 안이나 맵 밖에 떨어져도 7초 뒤 돌아온다. 크로스헤어와 실제 탄착 지점이 일치한다.

### Phase 4 — 전투 (돌진형)
- [ ] 돌진형 적(임시 Cube), 머리/몸 `Hitbox`
- [ ] AI (`Idle`/`Chase`/`Attack`/`Hit`/`Dead`), 0.5초 공격 예고
- [ ] 플레이어 체력과 사망, 적 체력과 처치
- [ ] `Stage_Training` 씬, `StageManager` 클리어 판정

**완료 기준:** 헤드샷이면 즉사, 몸샷은 피해 없이 탄환이 떨어진다. 처치 보상은 1회만 지급된다. 7대 맞으면 사망한다. 3마리를 모두 잡으면 클리어된다.

### Phase 5 — 재료
- [ ] `RunBag` (전투 가방), 클리어 시 정산, 사망 시 삭제
- [ ] `InventoryManager` (종이조각, 종이, 물감 9색, 상한 500, 초과분 버림 알림)
- [ ] 전투 가방 표시 UI, 미술관 합성대 (조각 5개 → 종이 1장)
- [ ] `SaveManager`, 씬 이동과 재실행 후에도 데이터 유지

**완료 기준:** 사망하면 그 판 재료만 사라진다. 물감 드롭이 9색 중에서 랜덤하게 나온다. 재실행 후에도 수량이 유지된다.

### Phase 6 — 그림판
- [ ] 작업대 E키 → 그림판 UI, 플레이어 조작 차단과 복귀
- [ ] 펜 4단계, 색상 9종, 지우개
- [ ] 거리 기반 실시간 물감 소비, 잔량 0이면 그리기 차단

**완료 기준:** 마우스를 빨리 움직이든 천천히 움직이든 같은 선이면 소비량이 같다. 지우개는 물감을 쓰지 않고 돌려주지도 않는다.

### Phase 7 — 완성·저장
- [ ] 완성: PNG 저장 성공 후 종이 1장 차감, ID 발급, 작품 목록 등록
- [ ] 취소: 확인창, 미완성 그림 삭제, 물감 미반환, 종이 미소비
- [ ] 그리는 동안 5초 자동 저장, 비정상 종료 시 취소와 동일하게 처리

**완료 기준:** 종이가 없으면 완성할 수 없다. 저장에 실패하면 종이가 줄지 않는다. 강제 종료 후 다시 켜면 쓴 물감은 줄어 있고 미완성 그림은 없다.

### Phase 8 — 전시 (액자 1개)
- [ ] 액자 E키 → 작품 목록(스크롤) → 선택 → 텍스처 교체
- [ ] `gallery.json` 저장, 재실행 후 복구

**완료 기준:** 재실행 후에도 같은 그림이 걸려 있다.

> **═══ M1 MVP 완료 ═══**

### Phase 9 — 액자 9개와 엔딩
- [ ] 액자 9개 배치, 중복 전시 허용, "서로 다른 작품 N / 9" 표시
- [ ] 서로 다른 ID 9개 감지 → 확인창 → 회고 연출 → 엔딩 독백 → 타이틀
- [ ] `MainMenu`: 새 게임(덮어쓰기 확인), 이어하기, 갤러리 보기 전환
- [ ] 갤러리 보기 모드 (감상만 가능)

**완료 기준:** 중복이 섞인 9칸으로는 엔딩이 나오지 않는다. 내용이 같아도 ID가 다르면 엔딩이 나온다. 엔딩 후 이어하기가 비활성화되고 갤러리 보기만 가능하다.

### Phase 10 — 숲 스테이지
- [ ] `Stage_Forest` 지형(에셋), NavMesh
- [ ] 원거리형 (`KeepDistance`, 투사체)

- [ ] 적 7마리 배치, 훈련장 클리어 시 숲 해금

**완료 기준:** 방패에 막힌 탄환은 바로 다시 쓸 수 있고 피해는 0이다. 측면 헤드샷은 즉사한다. 1판이 약 4분이다.

- [ ] 시작·엔딩 독백 자막
