## 게임 흐름 (지금 실제로 되는 것)

1. **타이틀(0_Title)**: 시작 / 그림 보기 / 도움말 / 옵션(소리 크기, 마우스 감도, 게임 나가기). 양쪽에 정사각형 액자 2개 — 그림 보기에서 고른 작품을 왼쪽/오른쪽에 건다 (저장됨).
2. **미술관(1_Museum)**: 플레이어 시작 위치. 오른쪽 위에 창고 재료 표시.
   - 갈색 **지도 탁자**에서 E → 전투 장소 선택 팝업 (훈련장 / 숲은 잠김).
   - 베이지색 **종이 합성대**에서 E → 종이조각 5개로 그림용 종이 1장.
3. **훈련장(2_Training)**: 돌진형 적 3마리. 모두 헤드샷으로 처치하면 클리어 → 재료가 창고로 → 미술관 복귀, 숲 해금 저장. 죽으면 그 판 재료를 잃고 미술관 복귀.

## 시스템별 정리

### 플레이어
- WASD 이동(4.5m/s), Shift 달리기(7m/s), Space 점프(1.5m), Q 회피(3m, 쿨 1.2초, 무적 0.3초).
- 3인칭 카메라: Cinemachine ThirdPersonFollow, 오른쪽 어깨 뒤 3.5m. 마우스 감도는 옵션 배율 적용.
- 체력 100, 전투 중 회복 없음. 체력바 왼쪽 위(사용자가 옮김).
- 스크립트: `PlayerMovement`, `ThirdPersonCamera`, `PlayerHealth`, `PlayerControlLock`(팝업 중 조작 정지).

### 한 발 탄환 (`OneBulletGun`)
- 좌클릭 발사. 카메라 중심 레이 → 조준점 → 총구에서 다시 판정.
- **머리 명중 = 처치 + 탄환 즉시 재사용.** 몸샷·빗나감 = 탄환이 바닥에 떨어져 쏠 수 없음.
- 떨어진 탄환: E로 회수(2m) 또는 **7초 후 자동 복귀**. 크로스헤어 둘레 노란 고리 = 남은 시간, 화면 밖이면 가장자리 화살표, 탄환 위 6m 빛 기둥.
- 최대 사거리 50m.

### 적 (돌진형 `Enemy_Charger`)
- 회색 상자 몸 + 큰 공 머리 (임시). 모든 부분 `Enemy` 태그.
- AI: 15m 안에 오면 추적(4m/s) → 4m에서 0.5초 뒤로 젖히는 예고 → 9m/s 돌진(0.5초) → 0.8초 숨 고르기. 몸에 맞으면 0.25초 멈칫.
- 돌진 피해 15 (7대에 사망). 처치 시 종이조각 1 + 랜덤 1색 물감 50.
- 스크립트: `EnemyHealth`, `EnemyAI`, `EnemyDrop`, `Hitbox`(Body/Head).

### 재료와 저장
- 전투 가방(`RunBag`): 이번 판 재료, 화면 오른쪽 위 표시.
- 창고(`InventoryManager`): 종이조각, 그림용 종이, 물감 9색(색마다 최대 500, 넘치면 버리고 "가득 참" 알림).
- 저장(`SaveManager`): `SavedData/save.json` — 재료, 해금 스테이지, 엔딩 여부, 타이틀 액자.
- 작품(`PaintingLibrary`): `SavedData/paintings.json` + `Paintings/painting_<ID>.png`. 그림판의 "완성"이 여기에 등록할 예정.

## 그동안 사용자가 바꾼 결정
- 몸샷 피해 없음(헤드샷 원탭 전용), 적 HP 없앰.
- 자동 복귀 15초 → 7초. 벽 자국 0.4초.
- 게임은 타이틀에서 시작, 미술관에서 팝업으로 전투 장소 선택.
- 씬 이름 번호 + 영어 (0_Title, 1_Museum, 2_Training).
- 모든 UI·오브젝트에 그림 바꿔 끼울 자리 (`Assets/UI/*.png`, 전용 머티리얼). 체력바·버튼·팝업 모두.
- 액자·그림 종이 정사각형 고정.
- 플레이어·적 모델은 3ds Max로 직접 만들 예정 (FBX → `Assets/Models/`).
