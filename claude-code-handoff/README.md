# Claude Code 세션 인계 패키지

새 Claude Code 세션으로 넘어갈 때 필요한 정보와 지침을 모아 둔 파일들입니다.

## 파일 구성

| 파일 | 용도 |
|---|---|
| `README.md` | 이 문서. 파일 구성과 사용 방법 |
| `CLAUDE.md` | Claude가 따를 작업 지침. 프로젝트 폴더 맨 위에 두면 새 세션이 시작될 때 자동으로 읽힘 |
| `SESSION_HANDOFF.md` | 이전 세션에서 있었던 일과 아직 해결되지 않은 문제 요약 |
| `CLAUDE_CODE_GUIDE.md` | Claude Code 기본 사용법 (모델, 노력 수준, 코드 리뷰 등) |

## 사용 방법

1. 작업할 프로젝트 폴더를 정합니다.
2. `CLAUDE.md`를 그 프로젝트 폴더 **맨 위(루트)** 에 복사합니다.
3. 나머지 파일은 같은 폴더나 `docs/` 같은 하위 폴더에 둡니다.
4. 새 Claude Code 세션을 그 프로젝트 폴더에서 시작합니다.
5. 첫 메시지로 이렇게 보내면 이전 맥락을 이어받습니다.

```
SESSION_HANDOFF.md 읽고 이어서 진행해줘
```
